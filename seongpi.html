성피솔루션,
매장전용 게임사이트 구축

성인PC방 손님이 매장 PC에서 사용하는 게임사이트와 게임 API, 피시방별 관리자, 롤링 리포트와 서버 환경을 한 번에 구성합니다. 하나의 성피사이트 아래 여러 피시방을 연결해 매장별로 관리합니다.

제공 기능 보기성피솔루션 문의
성피 구조

성피사이트 1개 아래 피시방 1·2·3을 하위 매장으로 등록하고, 각 피시방은 자기 매장의 손님을 관리하며 상위 관리자는 전체 현황을 확인합니다.

성피솔루션 제공 범위

매장 오픈에 필요한 시스템을 함께 제공합니다

사이트 화면만 제작하는 방식이 아닙니다. 손님이 게임을 고르는 화면부터 공급사 연결, 매장 관리자와 서버까지 같은 환경으로 세팅합니다.

01

손님용 게임사이트

카드게임, 고스톱, 섯다, 슬롯과 라이브 카지노를 종류별로 찾을 수 있는 게임 로비를 제작합니다. 매장 PC와 모바일에 맞는 반응형 화면으로 구성합니다.

02

게임 공급사 API

계약된 공급사의 게임 목록, 썸네일, 실행 주소와 점검 상태를 성피사이트에 연결합니다. 여러 공급사를 한 로비에서 이용할 수 있게 통합합니다.

03

피시방별 관리자

각 피시방은 자기 매장의 손님과 이용 내역을 관리합니다. 다른 매장의 자료는 보이지 않도록 계정과 메뉴 권한을 분리합니다.

04

매장 롤링 리포트

피시방별 롤링 내역, 적용 기준과 기간별 합계를 조회합니다. 상위 관리자는 전체 매장을 비교하고 각 매장은 자기 자료를 확인합니다.

05

브랜드·배너 설정

상호, 로고, 색상, 메인 배너와 공지를 적용합니다. 게임 노출 순서와 점검 상태는 관리자에서 변경할 수 있게 구성합니다.

06

서버·업데이트 지원

도메인, SSL, 기본 서버, 접근 기록과 백업 환경을 준비합니다. 게임 추가, 공급사 점검과 공통 기능 업데이트를 계약 범위에서 지원합니다.

매장 연결 구조

사이트는 하나, 피시방 관리는 각각

매장마다 별도 사이트를 만드는 것이 아니라 하나의 성피사이트에 피시방을 계속 추가하는 구조입니다.

상위 관리자

전체 피시방 계정, 게임 구성, 공지와 매장별 롤링 자료를 확인합니다. 새 피시방을 추가하고 매장별 권한과 적용 기준을 설정합니다.

공통으로 바꿀 배너와 게임 목록은 한 번에 반영하고 매장별로 다르게 적용할 항목은 따로 설정할 수 있게 구성합니다.

피시방 관리자

각 피시방은 매장을 찾은 손님과 자기 매장의 이용 내역을 관리합니다. 상위 설정이나 다른 피시방의 자료는 볼 수 없도록 권한을 나눕니다.

자주 확인하는 매장 현황과 롤링 리포트를 첫 화면에서 바로 볼 수 있게 메뉴를 단순하게 구성합니다.

매장 손님

손님은 피시방 PC에서 성피사이트에 접속해 게임 종류를 확인하고 원하는 콘텐츠를 실행합니다. 많은 게임이 등록돼도 카테고리와 검색으로 빠르게 찾을 수 있게 합니다.

점검 중인 게임과 이용 가능한 게임을 화면에서 구분해 불필요한 실행 오류를 줄입니다.

신규 피시방 추가

피시방이 늘어나면 새 매장 계정과 관리 기준을 추가합니다. 같은 게임사이트와 백오피스를 사용하므로 매장마다 다시 제작할 필요가 없습니다.

매장명, 담당자 권한과 리포트 기준을 설정한 뒤 사용할 계정을 전달합니다.

여러 매장을 한눈에 관리

상위 관리자는 전체 피시방을 보고, 각 매장은 자기 손님과 자료만 보는 구조로 복잡한 다매장 운영을 단순하게 만듭니다.

임대·비용 구성

기본형부터 필요한 범위만 선택합니다

완성된 데모를 먼저 보고 게임, 매장 수, 관리자와 서버 범위를 정한 뒤 초기 세팅과 월 이용 조건을 안내합니다.

기본 임대 구성

손님용 사이트, 백오피스와 기본 서버를 중심으로 구성합니다. 로고, 색상, 배너와 메뉴 등 기존 데모 안의 설정을 적용합니다.

게임 공급사

연결할 카지노·슬롯 공급사와 이용 조건에 따라 항목이 달라집니다. 기존 지원 규격과 신규 API 개발을 나눠 안내합니다.

맞춤 디자인·기능

전체 화면을 새로 디자인하거나 기본 관리자에 없는 기능과 리포트가 필요하면 별도 제작 범위로 구분합니다.

매장·서버 확장

피시방 수, 관리자 계정과 접속량이 늘어나면 필요한 서버와 관리 기능을 단계적으로 확장할 수 있습니다.

성피솔루션 적용 절차

데모 확인부터 매장 적용까지

화면과 관리자 기능을 먼저 확인하고 필요한 게임과 매장 구조를 정한 뒤 실제 운영 환경에 연결합니다.

사용자·관리자 데모 확인

게임 로비, 피시방 관리자, 상위 관리자와 롤링 리포트가 필요한 방식에 맞는지 확인합니다.

매장 구조와 게임 선택

연결할 피시방, 관리자 권한, 필요한 게임 공급사와 리포트 항목을 정리합니다.

브랜드·관리자 세팅

상호, 로고, 색상, 도메인, 배너와 매장별 관리자 계정을 적용합니다.

게임 API·리포트 테스트

게임 실행, 점검 상태, 매장별 자료와 관리자 권한이 정상적으로 반영되는지 검수합니다.

매장 연결과 운영 인계

피시방 PC에서 사이트를 확인하고 관리자 사용법, 오류 접수와 업데이트 범위를 전달합니다.

성피솔루션 FAQ

성피솔루션은 무엇인가요?
성인PC방 손님이 매장 PC에서 이용하는 게임사이트와 피시방별 관리자, 게임 API, 롤링 리포트와 서버를 함께 제공하는 솔루션입니다.
성피사이트와 각 피시방은 어떻게 연결되나요?
하나의 성피사이트 아래 피시방 1, 피시방 2처럼 하위 매장을 등록합니다. 각 피시방은 자기 매장의 손님과 내역을 관리하고 상위 관리자는 전체 매장을 확인합니다.
어떤 게임을 연결할 수 있나요?
계약된 공급사의 카드게임, 고스톱, 섯다, 슬롯과 라이브 카지노 게임을 API로 연결할 수 있습니다. 실제 제공 범위는 공급사 계약과 연동 규격에 따라 정합니다.
피시방이 늘어나면 사이트를 다시 만들어야 하나요?
같은 성피사이트 아래 새 피시방 계정과 매장별 관리 기준을 추가할 수 있게 구성하므로 매장마다 사이트를 새로 만들 필요가 없습니다.
성피솔루션 비용은 어떻게 구성되나요?
기본 임대료, 서버, 연결할 게임 공급사와 맞춤 디자인 또는 신규 기능 범위에 따라 구성됩니다. 기본 항목과 별도 항목을 나눠 견적을 안내합니다.
모바일에서도 사용할 수 있나요?
손님용 사이트는 PC와 모바일에 대응하는 반응형으로 구성할 수 있습니다. 매장 운영 환경과 연결 게임의 지원 기기를 함께 확인합니다.
